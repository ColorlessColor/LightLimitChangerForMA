# LightLimitChanger
VRChatで使用するアバター向けに、各種シェーダーの動的アニメーションを生成するツールです。

## 特徴
Modular Avatar を前提として、非破壊でアバター内のマテリアルの制御アニメーションを生成します。  
- lilToon・Poiyomi Toon・Sunao・UnlitWFシェーダーに対応
- 多機能な制御メニュー(明るさの上限下限・色の変更など)

## インストール
